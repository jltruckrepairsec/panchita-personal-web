## The blocker this whole section shares

The browser never names a domain and never routes — it sends one message and
renders one reply, and whatever selection happens, happens inside the Gateway.
So **this repository cannot see any of them.**

Until the module contract is written — how the Gateway picks a domain, what it
receives, what it must return — no page here can move past concept. Tracked as
[09 · B3](../09-backlog/blocked.md).

## Three domains gated on security, not on effort

[Financial](financial.md), [Capital](capital.md) and [Recruiter](recruiter.md)
all touch money or data about people who are not the owner.
[Care](care.md) probably does too. None should be built before
[04 · Permissions](../04-security/permissions.md) and
[04 · Audit](../04-security/audit.md) are real.

## A note on the external skills

Several pages reference assistant skills that exist outside this repository.
Those skills are the closest thing to a written specification of the work, but
they are **configuration, not source** — unversioned here and able to change
without a commit. Pointers, never the record.
