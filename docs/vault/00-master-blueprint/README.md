## Two rule sets, deliberately separate

* [**Core Principles**](principles.md) — what the owner has **declared**. Nine
  of the fourteen are not implemented, and the page says so per principle.
* [**Constitution**](constitution.md) — what the code **already does**, inferred
  from evidence.

Never merge them. The first is intent and the second is fact, and a vault that
blurs them starts claiming the system does things it does not.

## Vision is not the Blueprint

[Vision](vision.md) is the long-term strategic direction and purpose.
[The Master Blueprint](panchita-master-blueprint.md) is the structured
architectural and organizational map used to preserve and execute it. Settled by
owner decision on 2026-09-10.
