## The dependency running through this section

Teaching and simulation both need something to teach *from*. Today
[05 · SOPs](../05-knowledge/sops.md) is empty: the most valuable procedure in the
project — build risky work as a separate artefact, reproduce the failure in a
test, fix, verify the test fails against the pre-fix code — is followed
faithfully and written down nowhere.

**So this whole section is blocked on knowledge being captured, not on
capability being built.** That is worth knowing before anyone starts here.
